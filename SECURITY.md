# Security

Please report security problems privately, not in a public issue.

Email imhalawa@outlook.com with:

- What the problem is and what it could expose.
- How to reproduce it.
- The on-my-watch version.

Please wait for a fix before sharing details in public.

on-my-watch runs `pup` and `gh` with your own sign-in and keeps its data in `~/.on-my-watch/`. A problem that lets it reach further than that, or leak what it keeps, is a security problem.
